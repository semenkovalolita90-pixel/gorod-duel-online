# ГОРОД: Дуэль капиталов — online

Онлайн-приложение для двух игроков: комнаты по коду, состояние партии на сервере, SQLite persistence, переподключение, серверная проверка игровых действий и сделки с подтверждением принимающей стороны.

## Запуск локально

Требуется Node.js 20+ и npm.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. Для проверки с двух устройств в одной Wi-Fi-сети откройте `http://IP-АДРЕС-КОМПЬЮТЕРА:3000` на обоих устройствах. Для доступа через интернет нужен публичный хостинг с поддержкой Node.js и WebSocket/Socket.IO.

## Деплой

1. Загрузите папку проекта в Git-репозиторий.
2. Разверните как Node.js web service у хостинг-провайдера.
3. Build command: `npm install`; start command: `npm start`.
4. Убедитесь, что хостинг сохраняет постоянный диск для файла `gorod.sqlite`, либо задайте `DB_PATH` на persistent volume.
5. Используйте HTTPS. При необходимости задайте `ALLOWED_ORIGIN` точным origin сайта.

## Важно для production

- Для нескольких параллельных экземпляров сервера потребуется общий Redis adapter для Socket.IO и централизованное хранилище/транзакционная база; SQLite-файл на локальном диске подходит для одного экземпляра.
- Перед публичным запуском добавьте rate limiting, CSRF/origin policy, логи аудита, резервные копии и тесты на конкурентные действия.
- Игровая экономика и действия проверяются сервером. Браузер не может напрямую задать баланс или список собственности.
- Код комнаты — приглашение, а не секретный пароль; не используйте его как средство аутентификации для конфиденциальных данных.
- В текущей версии доступ к повторному подключению основан на токене в локальном хранилище браузера. Не очищайте данные сайта, если хотите восстановить эту сессию с того же устройства.
